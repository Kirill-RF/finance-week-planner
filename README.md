# План на финансовую неделю (Excel + генератор)

Excel-файл, который автоматически рассчитывает планы менеджеров по **финансовым неделям
(четверг — среда включительно)** из месячных планов, с учётом **стыков месяцев** и
**пропуском выходных дней**.

## 📂 Состав репозитория

| Файл | Назначение |
|---|---|
| **`План на фин неделю (обновлённый).xlsx`** | Рабочий файл (актуальная версия, 6 листов, расчёт сен.2026 — дек.2027, 23 направления, 71 фин. неделя) |
| `План недели - дополнение.xlsx` | Исходные данные: имена менеджеров и месячные планы (отсюда генератор берёт планы) |
| `План на фин неделю.xlsx` | Первая версия файла (12 менеджеров, придуманные имена) — оставлена для истории |
| `build_workbook_v2.py` | Генератор актуального файла: `python3 build_workbook_v2.py` |
| `recalc.py` | Пересчёт формул и запись кэшированных значений в xlsx (нужен, чтобы файл показывал числа в Google Sheets / мобильных просмотрщиках; Excel пересчитывает сам) |
| `verify_rebuild.py` | Независимая сверка всех чисел в файле с бизнес-логикой, посчитанной заново |
| `build_workbook.py`, `verify*.py`, `check_values.py` и др. | Скрипты первой версии и проверки |

## 📊 Описание Excel-файла «План на фин неделю (обновлённый).xlsx»

Файл состоит из 6 листов. **Жёлтые ячейки — редактируемые**, всё остальное считается формулами.

### 1. «План на фин. неделю» (главный лист для сотрудников)
* **ТАБЛИЦА 1**: строки — менеджеры (направления), столбцы — финансовые недели периода
  (`№ недели`, `Период чт–ср`, `Рабочих дней`). На каждой неделе стоит план конкретного
  сотрудника: нашёл свою фамилию + активную неделю → увидел свой план.
* Активная неделя **подсвечивается цветом** (условное форматирование) по активной дате.
* Строка `ИТОГО` — суммарный план отдела на неделю.

### 2. «Планы менеджеров» (основой ввод)
* Колонки — месяцы (Сентябрь 2026 … Декабрь 2027), строки — менеджеры, значения — **месячные планы**.
* Строка **«Рабочих дней месяца»** — количество рабочих дней каждого месяца (тянется с листа «Рабочие дни»).
* **ТАБЛИЦА 2 «Активная неделя»**: поле `Активная дата` (можно поставить `=СЕГОДНЯ()`) →
  автоматически определяется № и период активной фин. недели и план каждого менеджера на неё.

### 3. «Рабочие дни» (справочник)
* На каждый месяц — число рабочих дней (формула `SUMPRODUCT` по календарю) и число фин. недель.
* Таблица границ всех финансовых недель: `№`, `Начало (чт)`, `Конец (ср)`, `Рабочих дней в неделе`.

### 4. «Календарь» (служебный)
* Каждый день периода: дата, ключ месяца `ГГГГММ`, день недели, флаг `Рабочий день (1/0)`.
* **Чтобы отметить праздничный день — поставьте 0 в колонке D**, все планы пересчитаются.

### 5. «Расчёт» (служебный, не редактировать)
* **Блок 1**: план на каждый день = `план месяца / рабочих дней месяца`; в выходной = 0.
* **Блок 2**: план недели = сумма планов её 7 дней. Дни недели, попавшие на разные месяцы
  (**стык месяцев**), считаются по плану каждого месяца; колонка `Проверка A+B=итого`
  контролирует разбивку (должно быть `OK`).

## 🔢 Логика расчёта

```
план дня    = план месяца / рабочих дней месяца   (сб, вс = 0)
план недели = Σ планов 7 дней (чт…ср)
неделя на стыке двух месяцев = часть по плану мес. A + часть по плану мес. B
```

Пример (дата 22.10.2026 → неделя №9, 22.10–28.10): вся неделя в октябре, план «Ангарск»
= 8 110 000 / 22 РД × 5 рд = **1 843 181,82**. Неделя №10 (29.10–04.11) — стык:
3 дня по октябрю + 2 по ноябрю = 1 530 371,72 + ... — разбивка видна в «Расчёт», блоки E/F.

## 🛠 Как управлять

1. **Изменить месячный план** — жёлтая ячейка на «Планы менеджеров». В Excel числа обновятся сами.
2. **Отметить праздник** — в «Календаре» обнулить флаг рабочего дня.
3. **Посмотреть план текущей недели** — в ТАБЛИЦЕ 2 поставить активную дату (`=СЕГОДНЯ()`).
4. **Новый месяц/год** — правите `START_YM` / `N_MONTHS` в `build_workbook_v2.py`, запускаете:
   ```bash
   python3 build_workbook_v2.py && python3 recalc.py "План на фин неделю (обновлённый).xlsx"
   ```
5. **Проверить корректность файла** после любых правок кода:
   ```bash
   python3 verify_rebuild.py   # должно быть: ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ
   ```

⚠️ Если файл открывается в Google Sheets или мобильном просмотрщике — после ручной правки
в Excel прогоните `recalc.py`, чтобы обновился кэш значений (в самом Excel это не нужно:
он пересчитывает формулы при открытии, файл сохранён с `fullCalcOnLoad=1`).
